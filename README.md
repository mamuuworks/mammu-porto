# mammu-portofolio

A minimalist video portfolio for an independent filmmaker and visual storyteller. Built with React, Vite, Tailwind CSS, Lucide, and Three.js.

## Features
- React single-page app with lightweight history-based navigation
- Responsive monochrome editorial layout and generous whitespace
- Interactive project showcase and project detail overlay
- Animated Three.js wireframe sculpture in the hero
- Home, About Me, Pricing, Contact, and Terms of Service pages
- Responsive mobile navigation and reduced-motion support

## Getting started
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Customize before launch
- Replace the sample projects and Unsplash images in `src/App.jsx` with your own film stills or video embeds.
- Update `hello@mammu.studio` and the social links to your real contact details.
- Review the sample package pricing and Terms of Service for your business.
